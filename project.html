1. System Architecture Layers

1. Presentation Layer

Pure HTML5 semantic structure styled with modern Vanilla CSS3 design tokens, Glassmorphism, CSS Grid, and responsive flex layouts.

index.html view.html create.html style.css

2. Auth & Guard Layer

Client-side authentication controller powered by Firebase Auth SDK. Handles user login, OAuth sign-in, and route guards.

auth.js onAuthStateChanged Google OAuth

3. Database & Storage

Cloud Firestore NoSQL real-time database storing articles, user accounts, comments, and like counters with security rules.

firebase-config.js blog-service.js Firestore NoSQL

2. Cloud Firestore Database Schema

users
Collection
  • uid (PK) String
  • displayName String
  • email String
  • photoURL String
  • role String
  • createdAt Timestamp
blogs
Collection
  • id (PK) String
  • title String
  • category String
  • content HTML / Text
  • authorUid (FK) String
  • likesCount Number
comments
Collection
  • id (PK) String
  • blogId (FK) String
  • userUid (FK) String
  • content String
  • createdAt Timestamp
likes
Collection
  • id (blog_uid) String
  • blogId (FK) String
  • userUid (FK) String
  • createdAt Timestamp

3. End-to-End User & Data Workflow

1
Authentication
User logs in via Email/Password or Google OAuth. Firebase returns UID & JWT token.
2
Route Protection
auth.js checks user state before permitting access to create.html or edit.html.
3
Firestore CRUD
Author publishes post -> Firestore addDoc() executes -> Realtime Feed updates.
4
Engagement
Readers like post & submit comments -> Atomic transaction updates counters.

4. Implementation Roadmap & Timeline

Phase 1: SDK Setup & Configuration
Include Firebase App, Auth, and Firestore JS SDK scripts via CDN into HTML files and configure firebase-config.js.
Phase 2: Authentication & User Profiles
Build Login/Register modal interface, hook up Auth state listeners, and dynamic navbar user profile dropdowns.
Phase 3: Database Feed & CRUD Migration
Migrate feed rendering from localStorage to Cloud Firestore `getDocs()` with live search and category filtering.
Phase 4: Comments, Likes & Dashboard
Implement real-time comments on view.html, post like counters, user profile page, and author post management.
